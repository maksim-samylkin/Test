# Библиотека консольного взаимодействия с документами

Простой проект на С++ для работы с тестовыми документами через консольное менюю
Сделан и выполен по принципу TDD (разработка через тестирование) как отдельная подключаемая библиотека.

## Требования
1. Показать главное меню с действиями:
   - Выбрать документ(редактирование)
   - Создать документ
   - Прочитать документ
   - Заполнить пустой документ
   - Выйти
2. Проверить ввод пользователя (числа от 1 до 5 в главном меню, от 1 до 3 в подменю)
3. при неверном вводе повторять запрос.
4. Работа с файлами через функции: создание, чтение, запись, удаление
5. Код покрыт unit-тестами

## функции работы с документами:
  - createDocument()
  - docunebtExists()
  - readDocument()
  - writeDocument()
  - deleteDocument()

 ## функции интерфейса:
  - runUI()
  - mainMenu()
  - subMenu()
  - askFilename()
  - getNumber()
